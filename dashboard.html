About This Collection

This is a curated collection of modern web applications showcasing various technologies and concepts:

  • Frontend Development: Modern HTML5, CSS3, and vanilla JavaScript
  • API Integration: Claude AI, Open-Meteo weather services
  • Data Persistence: Browser local storage functionality
  • Responsive Design: Mobile-first, works on all devices
  • User Experience: Smooth animations, intuitive interfaces
  • Real-time Updates: Live data fetching and processing

Technologies Used

  • HTML5: Semantic markup, modern web standards
  • CSS3: Gradients, flexbox, grid, animations, media queries
  • JavaScript (ES6+): Object-oriented programming, async/await, fetch API
  • APIs: Claude AI API, Open-Meteo Weather API, Geolocation API
  • Storage: Browser LocalStorage for data persistence
  • Design Patterns: Class-based architecture, event-driven programming

🚀 Getting Started

All apps are standalone HTML files that run directly in your browser. No installation or setup required!

  1. For Zoology Question Generator: You'll need an Anthropic API key (free tier available)
  2. For Todo App: Works offline with automatic local storage
  3. For Weather Dashboard: No API key needed, free Open-Meteo service
